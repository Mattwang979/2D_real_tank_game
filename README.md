# PENETRATION

俯視角二戰坦克對戰手機網頁遊戲，核心是擬真的裝甲、乘員與模組損傷模擬。
A top-down WWII tank game for phones (landscape) with realistic armor, crew and module simulation.

**▶ 線上遊玩 / Play:** https://mattwang979.github.io/2D_real_tank_game/

> 手機請橫向遊玩。用瀏覽器「加入主畫面」後會以全螢幕橫向啟動。

## 玩法

| 操作 | 說明 |
| --- | --- |
| 左半螢幕拖曳 | 移動搖桿：往哪個方向推，坦克就轉向開過去；往後拉會倒車。搖桿上的白色三角形是車頭方向，陰影區（R）是倒車區；地面上的箭頭顯示坦克實際會往哪走、往哪邊轉 |
| **開火鍵（搖桿）** | 按住拖曳＝轉砲塔，**放開＝開火**；拖出去再拉回中心放開＝取消；直接點一下＝朝目前方向開火。砲塔停在你瞄的方向，不會自動回正。放開時若還在裝填（1.6 秒內）或砲塔還沒轉到位，會等瞄準到位自動擊發 |
| 手剎 | 按住：急停；邊開邊轉向會甩尾 |
| 加速 | 8 秒引擎超載（冷卻 25 秒） |
| 煙霧 | 像開火鍵一樣拖曳選方向，放開丟出 3 顆煙霧彈；點一下往砲口方向丟。每輛車 2 次，煙幕持續 13 秒，會擋住雙方視線 |
| 維修 / 滅火 | 6 秒搶修履帶、引擎、變速箱、砲閂等（冷卻 35 秒）；起火時變成滅火鍵 |
| 補員（CREW） | 一台半履帶運兵車從陣地後方開過來，停妥後 4 秒換掉所有受傷 / 陣亡的乘員（冷卻 45 秒）。運兵車被任何一發打中就會被摧毀（對方不得分），補員中斷、冷卻 25 秒 |
| 照明彈（FLARE，夜戰） | 每車 2 發，拖曳選方向，在 85 m 外升空，照亮半徑 50 m 共 14 秒，光圈裡的坦克 300 m 外都看得到 |
| 偵察機 / 砲擊 | 連殺獎勵：一條命內擊毀 2 台叫偵察機，3 台叫砲擊（見下方「連殺獎勵」） |
| 💬 無線電 | 小地圖旁的對話按鈕開 8 個快捷指令：進攻 / 防守 A 點、支援我、那裡有敵人（標在準星處）、跟我來、收到、不行、謝了。點小地圖可以在該處標記給全隊看 |
| ＋ / － 或雙指捏合 | 縮放：0.6× / 1× / 1.6× / 2.4×。放大時畫面會像瞄準鏡一樣推到目標附近，**手指按住戰場可讓砲口精準對準該點** |
| 彈種按鈕 | 切換穿甲彈 / 次口徑彈 / 高爆彈（換彈需要重新裝填） |

- **模式**：佔領中央的 A 點。佔住 A 點會持續扣敵方分數，擊毀敵車也會扣分；先把對方分數扣光、或消滅對方所有車輛就獲勝。
- **視野**：車身周圍一圈近距視野 + 沿砲管方向的錐形遠視野，會被建築物與煙幕遮擋；躲在樹叢裡較難被發現，開砲會暴露位置。
- **瞄準準星與弱點透視**：準星綠 = 可擊穿、黃 = 可能擊穿、紅 = 打不穿或會跳彈，上方顯示該部位的等效裝甲與你的穿深。被瞄準的敵車（放大時是畫面上所有敵車）會把每塊裝甲邊框標上同樣的顏色，一眼看出弱點。
- **陣容**：每場最多帶 3 台車，被擊毀後可以換下一台重新出擊。
- **AI 難度**：車庫的「AI」可選 **簡單 / 普通 / 困難**（預設普通），套用到戰場上雙方所有 AI 坦克。困難是原本的 AI：反應快、打得準、專打弱點；普通反應慢約 1 秒、每發之間會停頓、120 m 的命中率約只有困難的五到六成，而且很少瞄弱點；簡單更慢、更常打偏、從不瞄弱點。

## 連殺獎勵

- **偵察機**（一條命內擊毀 2 台）：依國籍派出 L-4 Grasshopper / Fi 156 Storch / Po-2，從我方後方俯衝進場、在敵方半場上空傾斜盤旋，再爬升離開。飛到定位後開始拍照：掃描波掃過地圖，所有敵車被框起來、在小地圖上閃爍，持續 10 秒（比分下方有倒數）。敵方叫來的偵察機也會出現在你的畫面上（並有「敵方偵察機！」提示），代表你們的位置馬上會曝光。
- **砲擊**（擊毀 3 台）：按下後打開**大張戰術地圖**（地圖格 A–H / 1–8，顯示看得到的敵我坦克）。點地圖放下落點，再拖曳右側的**放大鏡**微調（放大鏡裡是真實地面、坦克與煙幕），面板會顯示落點格位、距離、範圍內有幾台敵車，範圍內有隊友或自己時會警告；按 **開火（FIRE）** 才發射，約 3 秒後 8 發 150 mm 高爆彈落在半徑 11 m 內。

## 戰場

- **車身隱蔽地形**：每張地圖有面向據點的土堤、向後開口的 U 形掩體與大彈坑。躲在後面只露出砲塔（HUD 顯示 **HULL-DOWN**），打車身高度的砲彈會埋進土裡；開上土堤會變慢。
- **可破壞建築**：每發砲彈都會傷害房屋（高爆彈最有效），打到一半屋頂出現彈孔，打完會倒塌成廢墟，不再擋視線和砲彈。
- **天候與夜戰**：晴天 / 雨天 / 霧天 / 夜晚，可在車庫或房間選擇（或隨機）。天候影響視野距離、樹叢隱蔽與開砲暴露距離；雨天越野路面泥濘變慢；夜晚只看得到車組視線、照明彈、火光與砲口閃光照到的地方。
- **無線電與 AI 隊友**：快捷指令會出現在無線電紀錄與對話泡泡裡，並用瀏覽器語音唸出（可在設定關閉）。AI 隊友會聽令（佔點、防守、過來支援、跟隨、前往標記點）並回話，也會回報新發現的敵人。
- **擊殺重播**：被擊毀後約 1 秒，會從擊毀你的那台車的角度重播最後幾秒：看它把砲轉向你、慢動作追著那發砲彈飛過來、命中爆炸，然後才出現死亡畫面。可按 **略過 ▸**，也可以在設定關掉。
- **震動回饋**：開砲、被打中（跳彈輕震、擊穿重震）、擊毀敵車、附近爆炸、自己被擊毀都有不同的震動。Android 手機都支援；iPhone 的 Safari 不開放網頁震動（iOS 17.4–26.4 只有開砲和按按鈕時會有輕微觸感）。可以在設定關閉。

## 多人連線

在車庫按 **👥 多人連線**：

1. 一人按「建立房間」，會得到 5 碼房號（可按「邀請」分享連結，對方點連結就會直接進房）。
2. 其他人按「加入房間」輸入房號。最多 5 對 5，可以換隊、選地圖、改出戰陣容。
3. 房主可以設定 **AI 坦克：開 / 關** 與 AI 難度。開＝空位由 AI 補滿 5 對 5（補兵也由 AI 上場）；關＝只有真人對戰，這時兩隊都至少要有一位玩家才能開始。
4. 房主按「開始戰鬥」。打完會回到房間，可以直接再開一場。

- 連線方式是 WebRTC 點對點（[PeerJS](https://peerjs.com/) 的免費公用配對伺服器負責交換連線資訊），**戰鬥在房主的手機上運算**，房主請在戰鬥結束前保持遊戲開著（切到背景會讓所有人卡住）。
- 同一個 Wi-Fi 連線最穩；行動網路之間多數也能連（透過 PeerJS 的 TURN 中繼），少數嚴格的網路可能連不上。
- 有人斷線時，他的坦克由 AI 接手（關掉 AI 坦克時也一樣，避免少一台車）。

## 擬真損傷模擬

- 每台車有車體與砲塔的裝甲板（厚度、垂直傾角），依入射角換算等效裝甲；高角度會跳彈，大口徑可「過壓」(overmatch)。
- 履帶與裙板是間隙裝甲；次口徑彈打到裙板損失較多穿深。
- 擊穿後模擬彈芯與錐形破片進入車內，打到引擎、變速箱、油箱、彈藥架、砲閂與乘員（駕駛 D、無線電員 R、砲手 G、車長 C、裝填手 L）。
- 被帽穿甲彈（APHE）延遲引信在車內爆炸；高爆彈對開頂車與薄裝甲有超壓傷害。
- 彈藥架可能殉爆（砲塔被炸飛）、油箱與引擎可能起火；乘員陣亡後由其他乘員補位；按維修鍵可以搶修損壞的模組。
- 命中時右側會出現 **X 光擊殺畫面**，顯示彈道、破片與受損模組。

## 載具（23 台，美 / 德 / 蘇，四個階級）

USA：M24 Chaffee、M4A2 Sherman、M10 GMC、M4A3 (76) W、M18 Hellcat、M26 Pershing、M46 Patton
Germany：Sd.Kfz. 234/2 Puma、Pz.Kpfw. IV H、StuG III G、Panther D、Panther G、Tiger I、Tiger II (H)
USSR：T-34 (1941)、SU-85、T-34-85、IS-1、T-44、IS-2 (1944)、ISU-122S、IS-3、T-54 (1949)

數據為史實近似值。戰鬥獲得 RP（研發點數）與 CR（銀幣），在科技樹研發並購買新車；進度存在瀏覽器裡。

## 開發

```bash
npm install
npm run dev      # 本機開發伺服器
npm run build    # 輸出到 dist/
```

- TypeScript + HTML5 Canvas 2D + Vite，沒有遊戲引擎、沒有外部圖片或音效檔：所有坦克、地圖、特效都是程式繪製，音效用 WebAudio 合成。
- 推到 `main` 會由 GitHub Actions 自動建置並發佈到 `gh-pages` 分支（GitHub Pages）。
- `dev-sheet.html`（`npm run dev` 後開 `/dev-sheet.html?mode=tank|xray|armor`）可以一次檢視所有坦克的外觀、X 光與裝甲圖。

```

  game/tank.ts         坦克物理、砲塔、裝填、乘員補位、維修

  game/ai.ts / nav.ts  AI 指揮官與 A* 尋路
  game/difficulty.ts   AI 難度參數（瞄準誤差、反應、停頓、弱點、支援使用）
  game/vision.ts       視野多邊形與偵察
  game/map.ts          三張地圖的程序化佈局、土堤 / 掩體 / 彈坑、建築損壞
  game/carrier.ts      補員運兵車
  game/support.ts      連殺獎勵：偵察機航線（俯衝、盤旋、爬升）與砲擊
  game/weather.ts      天候、夜戰與照明彈
  game/radio.ts        無線電快捷指令
  game/replay.ts       錄下最近幾秒的戰況（擊殺重播用）
  core/haptics.ts      震動回饋
  core/voice.ts        無線電語音
  render/killcam.ts    擊殺重播：鏡頭、慢動作、用錄影重建畫面
  render/planeRender.ts 三款偵察機的程式繪圖
  render/*             坦克繪製、地圖分塊快取、戰鬥畫面、天候特效與戰爭迷霧
  net/peer.ts          PeerJS 包裝（房號、連線）
  net/session.ts       房間與連線戰鬥：房主權威模擬、快照同步、輸入與特效轉送
  ui/lobby.ts          多人連線大廳
  ui/artyMap.ts        砲擊用的大張戰術地圖與放大鏡
```

### 測試腳本

`scripts/` 裡是 Playwright 自動化測試（需要先 `npm run dev`）：`touch2.mjs` 測觸控操作，`mp.mjs` / `mp4.mjs` / `mpai.mjs` 用本機 PeerServer（`?peerhost=127.0.0.1&peerport=9000`）測多人連線與房間的 AI 開關，`sim.mjs` 跑整場 AI 對戰（`AI=easy|normal|hard`），`aiaccuracy.mjs` 量三種難度在 60 / 120 / 200 m 的命中率；`carrier.mjs`、`hulldown.mjs`、`building.mjs`、`support.mjs`、`weather.mjs`、`radio.mjs`、`killcam.mjs` 分別測補員、隱蔽地形、建築、連殺獎勵（偵察機與砲擊地圖）、天候夜戰、無線電、擊殺重播與震動；`hangarlayout.mjs` 檢查車庫在各種手機尺寸、中英文下不會重疊。
